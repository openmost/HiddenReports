## Documentation

__Hide a report for one website__

1. Go to __Administration > Websites > Hidden reports__.
2. Select the website at the top of the page.
3. Open a category, or use the search field.
4. Switch the report to __Hidden__. The change is saved immediately.

Use the switch in the header of a category to hide or show all its reports at once.

The report disappears from the reporting menu of this website. A subcategory whose reports are all hidden disappears from the menu too.

__Hide a report for all websites__

1. As a super user, go to __Administration > System > Hidden reports__.
2. Switch the report to __Hidden__.

The list is built from the website selected at the top of the page. Reports bound to a single website (goals, custom dimensions, custom reports) are only available on the website page.

__Show a report again__

Switch the report back to __Visible__. As the report was never removed from archiving, its full history is available right away.
